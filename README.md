## 🔄 Revision Strategy

When revising, focus on understanding the **pattern behind the solution**, rather than memorizing individual queries.

For each problem, try to answer:

* What is the problem actually asking?
* Which tables and columns are relevant?
* Do I need a `JOIN`?
* Do I need aggregation?
* Would a window function make the solution easier?
* What edge cases should I consider?
* Can I solve it in another way?

## 🎯 Goal

The goal is to build a strong understanding of SQL by repeatedly solving and revising problems until common SQL patterns become intuitive.

> **Practice → Understand → Revise → Repeat**
